# 💬 Real-Time Chat Application

A modern real-time chat application built using Flask and Flask-SocketIO that enables users to communicate instantly through live messaging. The application supports user authentication, group chat rooms, online user tracking, typing indicators, and message history storage.

---

## 🚀 Live Features

### Authentication

- User Registration
- User Login
- User Logout
- Session Management using Flask-Login

### Real-Time Communication

- Instant Messaging
- Real-Time Message Updates
- Group Chat Rooms
- Message Broadcasting

### User Presence

- Online User Tracking
- Join Notifications
- Leave Notifications
- Active User List

### Chat Experience

- Typing Indicators
- Message History
- Auto Scroll to Latest Message
- Chat Room Selection

### Modern UI

- Responsive Design
- Gradient Background
- Glassmorphism Effects
- Bootstrap Styling
- Mobile Friendly Layout

# ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/charanepuri/flask-realtime-chat-app
```

```bash
cd flask-realtime-chat-app
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Environment

Windows

```bash
venv\Scripts\activate
```

Mac/Linux

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```

Application will run at:

```text
http://127.0.0.1:5000
```
